4. Step-by-Step Deployment on Hostinger

Step 1: Buy Plan & Add Domain

  1. Go to hostinger.com and purchase the Business Web Hosting plan
  2. In hPanel, go to Domains → Add Domain → enter 7digitapi.com
  3. Point your domain's DNS to Hostinger (see Section 1)
  4. Enable SSL: hPanel → SSL → Install free SSL for 7digitapi.com

Step 2: Create MySQL Database

  1. hPanel → Databases → MySQL Databases
  2. Create a new database (e.g., u123456789_waamini)
  3. Note down: Database Name, Username, Password, and MySQL Host
Important: Hostinger MySQL host is NOT localhost. It's something like sql123.hostinger.com. Copy the exact value from hPanel.

Step 3: Import Database

  1. hPanel → Databases → phpMyAdmin → Open
  2. Select your database from the left panel
  3. Click Import tab → Choose File → select waamini_production_dump.sql
  4. Click Go. All 65 tables will be created with existing data.

Step 4: Configure db.php

On your local machine, open db_production_template.php, fill in the Hostinger values, and save as db.php:

define('DB_HOST', 'sql123.hostinger.com'); // from hPanel define('DB_PORT', 3306); define('DB_USER', 'u123456789_waamini'); // from hPanel define('DB_PASS', 'YourStrongPassword'); // from hPanel define('DB_NAME', 'u123456789_waamini'); // from hPanel define('APP_ENV', 'production'); define('APP_URL', 'https://7digitapi.com'); define('CRON_SECRET_KEY', 'your-64-char-random-string');

Step 5: Configure .env

Copy .env.production.template to .env and fill in all real API keys:

WHATSAPP_ACCESS_TOKEN=EAAxxxxxx... WHATSAPP_APP_SECRET=your_whatsapp_app_secret META_APP_SECRET=your_meta_app_secret OPENAI_API_KEY=sk-xxxxxx... RAZORPAY_KEY_ID=rzp_live_xxxxxx RAZORPAY_KEY_SECRET=your_razorpay_secret SMTP_HOST=smtp.gmail.com SMTP_USER=your@email.com SMTP_PASS=your_app_password APP_ENV=production APP_URL=https://7digitapi.com CRON_SECRET_KEY=same-as-in-db-php

Step 6: Upload Project Files

Recommended Method: ZIP your entire waamini project folder → hPanel → Files → File Manager → Navigate to public_html/ → Upload ZIP → Extract here

Alternative: Use FileZilla FTP. Get FTP credentials from hPanel → Files → FTP Accounts.

IMPORTANT: Files must be directly inside public_html/, NOT in a subfolder.
Correct: public_html/index.php, public_html/webhook.php, public_html/api/
Wrong: public_html/waamini/index.php
DO NOT upload these files:
  • waamini_production_dump.sql — already imported into database
  • db_production_template.php — template, not needed on server
  • .env.production.template — template, not needed on server
  • WAAMINI_Deployment_Guide.html — this guide
  • Any .git/, node_modules/, tests/, scripts/ directories

Step 7: Enable HTTPS Redirect

After SSL is working, edit .htaccess on the server. Find these lines (around line 126) and uncomment them:

RewriteCond %{HTTPS} off RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]

Step 8: Update WhatsApp Webhook URL

CRITICAL — WhatsApp won't work without this!
  1. Go to Meta Developer Console → Your App → WhatsApp → Configuration
  2. Change Webhook URL to: https://7digitapi.com/webhook.php
  3. Keep your Verify Token the same as before
  4. Ensure these webhook fields are subscribed: messages, message_deliveries, message_reads

7. Common Issues & Fixes

500 Internal Server Error

Hostinger uses LiteSpeed, not Apache. If mod_php directives in .htaccess cause errors, they're already wrapped in <IfModule> checks so they'll be safely ignored. If you still get 500 errors, create a php.ini or .user.ini file instead:

display_errors = Off log_errors = On allow_url_include = Off session.cookie_httponly = 1 session.use_strict_mode = 1 expose_php = Off

Database Connection Failed

Hostinger MySQL host is NOT localhost. Go to hPanel → Databases and copy the exact hostname (e.g., sql123.hostinger.com). Update db.php accordingly.

Cron Jobs Not Running

  • Use full PHP path: /usr/bin/php ~/public_html/cron_campaign_sender.php
  • Check hPanel → Advanced → Cron Jobs → Execution logs
  • SSH in and test manually: php ~/public_html/cron_campaign_sender.php

WhatsApp Webhook Not Receiving Messages

  • Verify SSL is active (Meta requires valid HTTPS)
  • Webhook URL must be exactly: https://7digitapi.com/webhook.php
  • Test: curl -I https://7digitapi.com/webhook.php should return 200
  • Check webhook_logs table in phpMyAdmin for incoming entries

File Permission Issues

Folders: 755 (rwxr-xr-x) PHP files: 644 (rw-r--r--) storage/: 755 (needs write access for uploads) .env: 600 (owner read/write only)

Session Issues After Login

If login works but dashboard shows "session expired," check PHP session settings in hPanel → Advanced → PHP Configuration, or add to .user.ini:

session.save_path = "/tmp" session.gc_maxlifetime = 3600
